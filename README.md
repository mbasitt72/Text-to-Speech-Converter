# Text-to-Speech-Converter

A simple Python-based Text-to-Speech Converter that converts written text into audio using Google's Text-to-Speech (gTTS) library.



Features:


Multiple Languages: Supports English, Urdu, Hindi, Arabic, French, and Spanish.

Speech Speed: Choose between normal and slow speech.

MP3 Generation: Converts text into downloadable MP3 audio files.

Custom File Naming: Allows users to specify the output audio filename.

Error Handling: Handles invalid language and speed selections.

Technologies Used

Python

Google Text-to-Speech (gTTS)

OS Module

 
Usage:



Run the Python program:

python text_to_speech.py

Follow the on-screen menu:

Select your preferred language.

Choose normal or slow speech.

Enter your desired output filename.

Enter the text you want to convert.

Your audio will be generated and saved as an MP3 file.
